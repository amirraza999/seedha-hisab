# Seedha Hisab SEO Roadmap

## Search positioning

Seedha Hisab should compete on transparent Pakistan-specific calculations: the calculator appears first, followed by the formula, assumptions, worked example, verification date and source. The site should not publish thin pages merely to target keyword variations.

Each calculator owns the transactional query. Each linked guide owns the explanatory query. Internal links connect both without making pages compete for the same main intent.

## On-page checklist

- One unique title, description, H1 and canonical per indexable page.
- Main keyword used naturally in the title, H1 or opening answer; no keyword stuffing.
- Calculator, formula, worked example, assumptions, verification period and sources visible.
- Descriptive internal anchors connect calculator ↔ guide ↔ category hub.
- Descriptive image filenames, dimensions and alt text retained.

## Technical checklist

- Crawlable canonical URLs only in `sitemap.xml`.
- `robots.txt` allows public content and identifies the sitemap and host.
- Legacy URLs use permanent redirects to canonical pages.
- Unknown routes use a crawlable-link 404 with `noindex`.
- WebSite, Organization, CollectionPage, ItemList, BreadcrumbList, Article and FAQPage structured data reflect visible content.
- Mobile navigation and page layouts avoid horizontal overflow.

## Ethical off-page plan

1. Make the site public and connect a custom domain before outreach.
2. Verify Google Search Console and Bing Webmaster Tools; submit `/sitemap.xml`.
3. Publish the original salary-slab table, marla-standard comparison and COD return scenario as the primary linkable assets.
4. Pitch relevant Pakistan tax, HR/payroll, property, e-commerce and freelancer publications with one genuinely useful resource per pitch.
5. Seek citations from accountants, payroll providers, property blogs, seller communities, universities and business associations where the tool directly helps their readers.
6. Create branded profiles only on legitimate relevant platforms; avoid bulk directory submissions, paid link networks, comment spam and reciprocal-link schemes.
7. Review referring domains, anchors, indexed pages and query performance monthly; improve pages that earn impressions but weak click-through.

Backlinks cannot be created inside this repository. They exist only when another independent website links to a public Seedha Hisab URL.
